# DayFlow — نسخهٔ اندروید (فایل نصبی APK)

این پروژه همان برنامهٔ DayFlow است که داخل یک پوستهٔ اندرویدی (Capacitor) قرار گرفته.
تفاوت مهم با نسخهٔ وب: **زنگ‌ها، یادآوری‌ها و پیش‌هشدارها با خود سیستم اندروید زمان‌بندی می‌شوند**
و حتی وقتی برنامه کاملاً بسته است هم می‌رسند.

> توجه: من این پروژه را اینجا نتوانستم کامپایل کنم (SDK اندروید و اینترنت نداشتم).
> منطق برنامه با یک شبیه‌ساز تست شده، ولی ساخت APK و اجرا روی گوشی برای اولین بار باید توسط خودت انجام شود.
> اگر مرحله‌ای خطا داد، متن خطا را برایم بفرست تا درستش کنم.

---

## راه ۱ — ساخت APK بدون کامپیوتر (GitHub Actions) ✅ پیشنهادی

۱. در github.com حساب بساز (رایگان) و یک مخزن جدید بساز (مثلاً `dayflow`).
۲. همهٔ محتویات این پوشه را در مخزن آپلود کن (Add file ← Upload files).
   - پوشهٔ مخفی `.github` باید آپلود شود. اگر در لیست آپلود دیده نشد: Add file ← Create new file،
     در نام فایل بنویس `.github/workflows/build-apk.yml` و محتوای فایل `build-apk.yml` همین پروژه را در آن بچسبان.
۳. به تب **Actions** برو ← «Build Android APK» ← **Run workflow**.
۴. حدود ۵ تا ۱۰ دقیقه صبر کن. بعد از سبز شدن، در پایین صفحهٔ همان اجرا بخش **Artifacts** ← `DayFlow-apk` را دانلود کن.
۵. فایل zip را باز کن، `app-debug.apk` را به گوشی بفرست و نصب کن
   (اگر خواست، «نصب از منابع ناشناس» را برای همان برنامهٔ فایل‌منیجر/مرورگر روشن کن).

## راه ۲ — ساخت روی کامپیوتر

نیازها: Node.js 20، JDK 17، Android Studio (برای SDK).

```
npm install
npm run android:add     # ساخت پروژهٔ اندروید + مجوزها + آیکون
npm run android:apk     # ساخت APK
```
خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

## تغییرات نسخهٔ اصلاح‌شده (رفع خطای بیلد)

- **خطای بیلد (exit code 1)**: در مرحلهٔ Build debug APK کلاس `ActivityResult` از مسیر اشتباه ایمپورت شده بود و کامپایل جاوا شکست می‌خورد؛ اصلاح شد (`androidx.activity.result.ActivityResult`).
- رمزگذاری کامپایل جاوا روی UTF-8 تنظیم شد (متن‌های فارسی داخل کد جاوا).
- **تقویم**: رویدادهای «تمام‌روز» با ساعت UTC ثبت می‌شوند و رویدادهای تکرارشونده به‌جای DTEND از DURATION استفاده می‌کنند (قبلاً ثبت آن‌ها خطا می‌داد). اگر رویداد قبلاً از تقویم پاک شده باشد، دوباره ساخته می‌شود.
- **زنگ‌ها**: زنگ‌های حذف/غیرفعال‌شده دیگر به صدا درنمی‌آیند (قبلاً آلارم قدیمی لغو نمی‌شد). اگر اجازهٔ «آلارم دقیق» داده نشده باشد، برنامه کرش نمی‌کند و از آلارم غیردقیق استفاده می‌کند.
- در Actions اگر بیلد خطا بدهد، گزارش کامل در Artifact با نام `build-reports` ذخیره می‌شود.

## بار اول که برنامه را باز کردی

۱. **اجازهٔ اعلان‌ها** را بده.
۲. اگر اندروید پرسید، اجازهٔ **«آلارم‌ها و یادآوری‌ها»** (زنگ دقیق) را روشن کن.
۳. برای اینکه گوشی هشدارها را نکُشد: Settings ← Apps ← DayFlow ← Battery ← **Unrestricted / بدون محدودیت**.
   روی شیائومی/سامسونگ/هواوی/اوپو، «Autostart / شروع خودکار» را هم برای DayFlow روشن کن.

## چطور کار می‌کند

- هر بار چیزی را اضافه یا ویرایش کنی (و هر بار برنامه را باز کنی)، هشدارهای ۲۱ روز آینده دوباره در اندروید ثبت می‌شوند:
  زنگ‌ها، یادآوری‌ها (با تکرار و پیش‌هشدار)، کارهای دارای هشدار و خلاصهٔ صبحگاهی.
- اگر بیش از ۳ هفته برنامه را باز نکنی، هشدارهای ثبت‌شده تمام می‌شوند؛ با یک بار باز کردن دوباره پر می‌شوند.
- با ریبوت گوشی، هشدارها توسط افزونه دوباره برقرار می‌شوند.
- پشتیبان‌گیری و فایل تقویم با منوی اشتراک‌گذاری اندروید ذخیره/ارسال می‌شوند.
- دکمهٔ «بازگشت» اندروید: پنجره را می‌بندد، بعد به «امروز» برمی‌گردد، بعد از برنامه خارج می‌شود.
- پنجرهٔ تمام‌صفحهٔ «زنگ» (با تعویق/انجام شد) فقط وقتی برنامه باز است نشان داده می‌شود؛ وقتی بسته است، اعلان اندروید می‌آید.

## به‌روزرسانی برنامه

فایل `www/index.html` را عوض کن (یا بگو من عوضش کنم)، در GitHub آپلود کن و دوباره Run workflow بزن.
چون امضای APK ثابت است (`keystore/dayflow-debug.keystore`)، APK جدید را **روی نسخهٔ قبلی** نصب می‌کنی و اطلاعاتت می‌ماند.

## محدودیت‌ها

- این APK از نوع debug است: برای نصب شخصی عالی است ولی برای انتشار در Google Play مناسب نیست.
- فونت وزیرمتن از اینترنت می‌آید؛ بدون اینترنت فونت پیش‌فرض گوشی نمایش داده می‌شود.
- صدای اعلان همان صدای پیش‌فرض اندروید است (نه زنگ ممتد مثل ساعت)؛ از تنظیمات اندروید ← اعلان‌ها ← «هشدارهای DayFlow» می‌توانی صدا را عوض کنی.
- اگر برنامه باز باشد، هم پنجرهٔ داخلی و هم اعلان اندروید ممکن است هم‌زمان بیایند.

## ساختار پوشه‌ها

```
www/                      خود برنامه (index.html و آیکون‌ها)
assets/                   آیکون اصلی برای ساخت آیکون‌های اندروید
scripts/patch-android.js  مجوزها، آیکون اعلان و امضای ثابت
keystore/                 کلید امضای ثابت
.github/workflows/        ساخت خودکار APK در GitHub
capacitor.config.json     تنظیمات Capacitor
```

## اتصال مستقیم به تقویم اندروید

در این نسخه، DayFlow می‌تواند رویدادها را مستقیماً داخل تقویم اندروید ثبت کند و دیگر برای افزودن به تقویم نیازی به ساخت فایل ICS یا «همگام‌سازی دستی» نیست.

- برای یادآوری‌ها: دکمه 📅 «افزودن مستقیم به تقویم»
- برای کارهای یک روز: از عملیات روز، افزودن مستقیم به تقویم
- برای برنامه‌های هشداردار: افزودن مستقیم همه موارد به تقویم
- در اولین استفاده، اجازه دسترسی به تقویم را تأیید کنید.
